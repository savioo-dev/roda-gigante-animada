# Roda Gigante Animada

Projeto front-end desenvolvido com **HTML5** e **CSS3** para praticar posicionamento absoluto, `transform-origin`, animações com `@keyframes` e layout responsivo.

## Funcionalidades

- Estrutura da roda gigante com 6 raios (`span.line`) e 6 cabines (`div.cabin`).
- Rotação contínua da roda (`360deg`) combinada com contra-rotação das cabines (`-360deg`) e transição de cores.
- Tipografia fluida com `clamp()` e adaptação de tamanho da roda em telas menores (`max-width: 500px`).
- Suporte a `prefers-reduced-motion` para acessibilidade.

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, Keyframe Animations, Media Queries)
